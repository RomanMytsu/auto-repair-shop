Live Demo · GitHub Repository

About the Project

Restart is a website for an automotive service company specializing in starter and alternator diagnostics and repair, automotive air conditioning services, and the sale of automotive components.

The website presents the company's services, service center network, product categories, and ready-made solutions for automotive repair shops.

This project was built with WordPress using a custom theme and exported as a static website for free hosting on GitHub Pages.

Deployment

The website is deployed on GitHub Pages as a static export of the original WordPress project.

GitHub Pages serves the generated HTML, CSS, JavaScript, and static assets without running WordPress or PHP.

Limitations

The deployed version does not include a running WordPress backend or database. WordPress administration and server-side functionality are therefore unavailable.

Contact form submissions and other backend-dependent features require a working backend or an external service to function correctly.
